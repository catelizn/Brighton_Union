# Дизайн-система Brighton Union

Отсылка к Брайтон-Бич (Нью-Йорк): индустриальная эстакада метро, стальные опоры,
ржаво-зелёные конструкции, тёмный асфальт. Линии метро B (оранжевая) и Q (жёлтая) —
акценты для HUD и критичных уведомлений.

## Основная тема «Индустриальная эстакада» (все UI: планшет, инвентарь, паспорт, меню)

| Роль | HEX | Применение |
|---|---|---|
| Фон | `#16191B` | фон всех окон, 60% площади |
| Плашка | `#2A3036` | карточки, поля ввода, списки, 30% |
| Обводка | `#3A434B` | рамки, разделители (сталь на полтона светлее плашек) |
| Акцент-зелёный | `#2E5A44` | шапки, кнопки, активная вкладка (поверх — белый текст) |
| Зелёный яркий | `#6BB38A` | микродетали: обводка выбранного предмета, индикаторы |
| Текст основной | `#E2E8F0` | весь основной текст |
| Текст вторичный | `#9AA7B4` | подписи, пояснения |

## Проверенные контрасты (WCAG)

Измерено скриптом (2026-08-24):

- `#E2E8F0` на `#16191B` — **14,3:1** (AAA) — основной текст.
- `#E2E8F0` на `#2A3036` — **10,8:1** — текст на плашках.
- белый на `#2E5A44` — **7,9:1** — текст на зелёном акценте.
- `#E2E8F0` на `#2E5A44` — **6,4:1** — допустимо.
- `#D97706` на `#111418` — **5,8:1** / на `#16191B` — **5,5:1** — оранжевый текст читается.
- `#EAB308` на `#111418` — **9,6:1** — жёлтый текст читается.
- белый на `#D97706` — **3,2:1** — ТОЛЬКО крупный/жирный текст; обычный текст на
  оранжевом — тёмный (`#111418`).
- `#2E5A44` на `#16191B` — **2,2:1** — зелёный НЕ использовать как текст/обводку на
  тёмном фоне; для этого есть яркий `#6BB38A`.

## Правила

1. Распределение 60/30/10: 60% фон, 30% компоненты, 10% акцент микродозами
   (активная вкладка, обводка выбранного, шкалы здоровья/денег).
2. Чистый белый `#FFFFFF` не использовать — только `#E2E8F0`.
3. Зелёный — для состояний «свой/доступно», оранжевый — «внимание», жёлтый — маркеры,
   красный `#D64545` — критично.
4. Все UI собираются на одних CSS-переменных (ниже) — палитру менять в одном месте.
5. Шрифтовая пара: Geometria (заголовки) + Montserrat (текст) — отсылка к стилю
   авторизации GTA5RP из _references.

## CSS-переменные

```css
:root {
    /* фоны */
    --bu-bg: #16191B;
    --bu-bg-hud: #111418;
    /* поверхности */
    --bu-surface: #2A3036;
    --bu-surface-hud: #1C2026;
    --bu-border: #3A434B;
    /* акценты */
    --bu-accent: #2E5A44;      /* зелёный эстакады */
    --bu-accent-bright: #6BB38A;
    --bu-accent-orange: #D97706; /* ветка B */
    --bu-accent-yellow: #EAB308; /* ветка Q */
    /* текст */
    --bu-text: #E2E8F0;
    --bu-text-dim: #9AA7B4;
    --bu-text-on-accent: #FFFFFF;
    --bu-text-on-warm: #111418;
    /* статусы */
    --bu-success: #3E8E5A;
    --bu-danger: #D64545;
    --bu-info: #4A7BA6;
}
```
