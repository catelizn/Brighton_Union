# Карта механик: RedAge 3.0 → FiveM/QBCore

Сводка исследования GitHub (2026-08-24). Для каждой механики из RedAge 3.0 — что есть
готового под FiveM, что брать за основу, а что писать с нуля.

Правило адаптации (см. BRIEF.md, раздел 11): всё, что берём, — только с переработкой,
особенно внешний вид. Никаких копий «1:1».

## Покрыто хорошо — берём готовое как каркас и перерабатываем

- **Казино** — `RyFiction/casino-reboot` (QBCore): рулетка, блэкджек, слоты, колесо удачи,
  обмен фишек. ⭐29, коммиты до 2025-06. Форк PEROXCYDE/casino — то же.
- **Бизнесы** — `Rencikas/ren-businesses` (MIT, ⭐113): владение, сотрудники, закупки,
  производство, продажа, уровни бизнеса. Плюс штатные qb-houses (дома).
- **Рыбалка** — `Lionh34rt/qb-fishing` (GPL-3.0, ⭐51): зоны, ловля, продажа. На forum.cfx.re
  есть бесплатные варианты с миниигрой и лидербордом.
- **Фермерство** — `trclassic92/qb-simplefarming` (GPL-3.0, ⭐96): посадка, полив, рост,
  сбор, продажа. Заброшен с 2023, но код простой и рабочий — дорабатывать.
- **HUD в стиле Majestic** — `majestic-development/majestic-hud` (Svelte, ESX/QB) —
  референс стиля. Альтернативы: ps-hud, sync-hud, cx-hud. Дизайн делать свой.
- **Магазин 24/7** — логика штатного qb-shops (активен) + современный UI от
  `QBCoreStore/qb-shops` (NUI с картинками и корзиной). Перерисовать под RedAge-стиль.
- **Выбор персонажа / авторизация** — `raiderss/qb-multicharacter` (GPL-3.0, ⭐14):
  переработанный UI/UX поверх QBCore. Альтернатива luke_multicharacter (qbx).
  Стиль GTA5RP — рисуем сами поверх базы.

## Покрыто слабо — есть только сырые наработки

- **Планшет** — открытого нормального планшета для QBCore нет (кандидаты: cs-tablet,
  lsfive-tablet, vCAD_ui — все слабые). План: свой NUI-планшет с приложениями;
  инфраструктуру можно переиспользовать от qb-phone (оба — NUI поверх QBCore).
- **Маркетплейс** — `Zartoz/zz-marketplace` (MIT, ⭐6, 2024) как логический каркас;
  свежие: qb-marketplace-community (июнь 2026), DudaPlus (авто-маркетплейс).
  UI делать свой, в идеале — приложение планшета.

## Готового нет — пишем сами (отличительная черта проекта)

- **Обучение новичков через квестовых NPC** (стиль Majestic): открытых аналогов нет.
  Каркас квестов — MST-MISSION (NPC + цепочки + награды, заброшен с 2023).
- **Система семей** (RedAge Family: создание, ранги, дом, склад, банк): есть только
  штатная qb-management (банды). Семейный слой — свой.
- **Порт RedAge/NeptuneEvo на FiveM** — не существует. Мы первые, кто делает это системно.

## Разбор RedAge 3.0 (клон в _references/redage_v3)

Сервер — C# проект NeptuneEvo (`dotnet/resources/NeptuneEvo/`), UI — Svelte (`src_cef/src/`).

Ключевые системы и их файлы:
- **Фракции** (`Fractions/`): полиция, шериф, FIB, EMS, мэрия, Weazel News, армия,
  банды, мафии. Ядро `Fractions/Manager.cs` (~3000 строк). Единая система рангов и прав
  (`Table/Models/`): RankData, DepartmentData, enum RankToAccess на 60+ прав — готовый
  шаблон «ранги+доступы» для фракций и семей.
- **Семьи** (`Organizations/`): создание через NPC, офис в отдельном измерении, склад,
  гараж, 14 схем крафта оружия. Аналогов «дома семьи» нет — у нас будет свой.
- **Бизнесы** (`Core/Businesses.cs`, ~4100 строк): 16 типов (24/7, заправка, 4 автосалона,
  оружейный, одежда, бургерная, тату, барбер, маски, LSC, автомойка, петшоп). Покупка
  через маркер, наценка, налог 2.6%, заказы поставок дальнобойщикам, банк бизнеса.
- **Дома** (`Houses/`): покупка через маркер (риэлторское агентство), типы от трейлера
  до люкса, мебель, соседи-ключи, гараж с апгрейдом, продажа государству/игроку.
- **Работы** (`Jobs/`): электрик, почтальон, такси, автобус, газонщик, дальнобойщик,
  инкассатор, механик + промыслы (шахта, лесоруб/грибы/охота). Прокачка уровнем за
  действия (jobskills), оплата = тариф × множитель уровня × VIP × MoneyMultiplier.
- **Квесты** (`Quests/`): NPC-диалоги, цепочка новичка `Quests/Main/Zdobich.cs`
  (~30 стадий: город → работа → права B → лицензия G → бизнес → семья → медлицензия).
  Готовый шаблон «обучение новичков».
- **Автошкола** (`Core/DrivingSchool.cs`): права 9 категорий A(мото)/B(авто)/C(грузовик)/
  V(вода)/LV(вертолёт)/LS(самолёт)/G(оружие)/MED/PM; авиация требует LVL 20; экзамен
  в сборке отключён (права покупаются). Нам нужен НАСТОЯЩИЙ экзамен + лётная школа.
- **Казино** (`NewCasino/`): блэкджек, рулетка, слоты, колесо удачи, скачки. Математика
  серверная — переносится.
- **Авторизация** (`Accounts/`, `Character/`): регистрация с GA, HWID, выбор персонажа.
- **Экономика** (`MoneySystem/`): Wallet/Bank, таблица `money` (счета игроков/домов/
  бизнесов), логи операций. Переносится как есть.

UI (Svelte, `src_cef/src/views/`):
- `player/newauthentication/` — авторизация, выбор/создание персонажа, выбор спавна.
- `player/hudevo/phonenew/` — телефон с 15+ приложениями (аукцион, объявления, GPS).
- `player/menu/` — игровое меню, инвентарь, фракционный планшет.
- `fractions/weazelnews/` — планшет Weazel News с платными объявлениями (наше требование).
- `fractions/policecomputer/`, `fractions/bortovoi/` — полицейский MDT/планшет.
- `house/rieltagency/`, `house/buymenu/` — недвижимость; `business/menu/` — магазин 24/7.
- `quests/dialog/` + `src/json/quests/npc_zdobich.json` — диалоги и обучение новичка.
- `player/help/` — энциклопедия работ/фракций/бизнесов (переиспользовать как контент).
- Транспорт UI: `api/rage.js` (mp.trigger/rage-rpc) → заменить на FiveM NUI-мост
  (fetch `https://<resource>/handler` + window message). Каркас router/store/popups
  переносится 1:1. Fluid-масштабирование Sass — идеально для NUI.

## Порядок реализации (обновлено 2026-08-24)

1. **Обучение новичков** (квестовые NPC) — шаблон RedAge Zdobich + UI диалогов. Визитная
   карточка сервера.
2. **Планшет** — свой NUI (в него встанут маркетплейс, Weazel News, семьи).
3. **Автошкола и лётная школа** — экзамены с чекпоинтами, права A/B/C/V/LV/LS (+G/MED/PM
   фракционные). В RedAge экзамен отключён — напишем настоящий.
4. **Работы с прокачкой 0–10**: дальнобойщик, почтальон, мясник, таксист, лесоруб,
   грибник + существующие (ферма, рыбалка). Единая система уровня и оплаты за действие.
5. **Мэрия** — приметное здание в центре, работники, лицензии, выборы (референс RedAge
   Elections.cs). Переработка qb-cityhall.
6. **Семьи** — поверх qb-management: создание, ранги, дом/офис, склад, банк.
7. **Маркетплейс** — как приложение планшета (референс Majestic Marketplace).
8. **Бизнесы и дома через маркер** — ren-businesses + qb-houses, покупка только через
   маркер, продажа через маркетплейс/Weazel News.
9. **Фракции**: 2 полицейских департамента, FIB, больница, Weazel News, работники мэрии.
10. **Казино** — casino-reboot с переработанным дизайном.
11. **Стилистика**: HUD, магазин 24/7, авторизация (заготовки shop24/ui/auth GTA5RP).
